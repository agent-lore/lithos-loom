**Build** `graph_layout.py` (pure, Foundation; map it in `docs/architecture.toml`):
- **SCC:** Tarjan over `blocks` + `waits_on_gate` edges of the fetched topology. Every SCC of size > 1, or a self-loop, is a cycle. Members sorted by (`created_at`, `id`); one representative path = DFS from the smallest member over adjacency sorted the same way. Output must be identical under reversed input order.
- **Condensed Kahn layering:** each SCC condensed to one node; each Lithos-flagged cycle member (a `kind="cycle"` blocker from `task_blocked`) that belongs to no SCC condensed alone; so every cycle member gets a layer and dependents are layered below, marked "blocked via cycle". Layers use ALL fetched dependency edges (active, inactive, unknown).
- **Roots:** every in-degree-zero node of the condensed graph plus one representative per *cyclic* condensation.
- **Longest blocking chain (D7):** over the condensed DAG of the **active** projection only, longest path by node count (a cyclic condensation counts once; ghosts count); ties → smallest (`created_at`, `id`) at each step. Also "chain through a given node". Result carries `exact | lower_bound`: lower bound when the scope is incomplete OR any `unknown` dependency edge exists anywhere in the fetched graph.
- **Hierarchy tree:** indented `parent_child` tree for the scope.

**Acceptance:** A→B→A with C blocked by B yields layers `[{A,B} cycle]`, `[C blocked-via-cycle]`; a DAG of depth 4 yields four layers; a ghost with only outgoing edges is in layer 0; the same SCC in reversed edge order renders the same member list and path; an in-scope A with a `kind="cycle"` blocker but no SCC is layered and marked; the depth-5 fixture's longest chain is the known one and the chain through its layer-2 node is the known sub-chain; a completed 3-chain beside an open 2-chain yields the open one; an incomplete node flags the chain lower-bound; an in-scope A blocked by an `unknown` ghost yields a chain flagged lower-bound that does not pass through the ghost; a disconnected `unknown` edge elsewhere also flags the global chain lower-bound (known chain of length 1 beside unknown X→Y reports "≥ 1"); on an epic fixture, open `A → completed B` puts neither B on the chain nor B in A's ancestry, and reopening B (fake) makes the edge active again; `completed A → open B` is `inactive`/`satisfied`; `completed A → completed B` is `satisfied` (precedence over `dependent_resolved`).
